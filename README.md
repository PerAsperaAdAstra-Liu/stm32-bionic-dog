# 仿生机器狗「旺财一号」工程说明

基于 **启明欣欣 STM32F407 高配版（STM32F407ZGT6）** + **SU-03T 离线语音模块** +
**SG90 舵机 x4** + **0.96 寸 OLED** 的课程设计工程。
代码风格用 **ST 标准外设库（标准库）**，与老师视频保持一致。

## 〇、硬件实物型号（按《固件参数和使用》核对）

| 模块 | 实物 | 关键参数 |
|---|---|---|
| 主控 | 启明欣欣 407 高配版 | STM32F407ZGT6，HSE 8MHz → 主频 168MHz |
| 语音 | SU-03T V1.8（带转接板） | 供电 **3.6~5.5V（用 5V）**，串口 9600-8-1-无校验，UART 电平 3.3V |
| 显示 | 0.96 寸 4 针 I2C OLED | 驱动芯片 **SSD1315**（与 SSD1306 指令兼容），128×64，丝印 `GND VDD SCK SDA` |
| 舵机 | **SG90** 9g 180° 模拟舵机 | 塑料齿、堵转扭矩 1.6kg·cm@4.8V、线长约 25cm |

> 两处与老师视频口述不同，按实物来：① SU-03T 实物标称供电 3.6~5.5V，
> 网上流传的"5~6.7V"不要照做，超压会损坏模块；② 实物舵机是 SG90（塑料齿），
> 比 MG90S 脆弱，**堵转容易扫齿**，首次调试先用收窄的脉宽范围（见"接线表"文档）。

## 一、目录结构

| 目录 | 内容 |
|---|---|
| `Common/` | 延时（SysTick）、位带操作宏、内核辅助函数 |
| `Main/` | `main.c` 主框架、`main.h` 指令映射表、`stm32f4xx_it.c` 中断向量 |
| `Startup_config/` | `stm32f4xx.h` 寄存器定义、`system_stm32f4xx.c` 时钟配置、启动文件 |
| `CMSIS_Core/` | 现代 CMSIS 内核头文件（Arm Compiler 6 需要，已复制的权威副本） |
| `STM32F4_FWLIB/` | 标准外设库：全部头文件 + 参与编译的 5 个驱动源文件（`src/` 里另有 2 个暂不使用的文件，未加入工程） |
| `USER/LED/` | 三盏板载指示灯（开灯/关灯指令） |
| `USER/SERVO/` | TIM4 四路 PWM 舵机驱动 + 动作库（起立/趴下/坐下/前进/后退） |
| `USER/USART6/` | 串口 6 接收语音模块指令 |
| `USER/OLED/` | OLED 软件 I2C 显示驱动（SSD1306/SSD1315 指令）+ `oled_picture.c` 表情资源 |
| `Project/` | `Dog.uvprojx` Keil 工程；`OBJ/`、`LIST/` 为首次编译后自动生成，仓库不含 |
| `Tools/` | 仅 `keilkill.bat`（清理编译产物）；表情 / 工程生成脚本不随仓库发布 |
| `Docs/` | SU03T 配置清单、接线表、联调验证清单、指令映射表 |

## 二、编译与下载

1. 双击打开 `Project\Dog.uvprojx`。
2. 首次使用先设一次调试器（之后会存进 `Dog.uvoptx`）：
   **Options for Target（Alt+F7） → Debug 页 → 右上角下拉选 `ST-Link Debugger`**
   → 勾选 `Reset and Run`（下载完自动运行）。
   Utilities 页确认 `Use Debug Driver` 已勾选，Flash Download 里有 `STM32F4xx 1MB` 算法。
3. `F7` 编译，`F8` 下载，`F5` 调试。

当前工程用 **Arm Compiler 6（AC6）** 编译，实测结果：

```
Program Size: Code=7222  RO-data=8722  RW-data=12  ZI-data=2668
0 Error(s), 0 Warning(s)
```

RO 合计约 **15.5 KB**，Keil Lite 版 32KB 上限仍有充足余量。
若日后装了 **Arm Compiler 5（AC5）**，同一份代码也能编译——本工程已经把 AC5/AC6
不兼容的地方处理好了（见"与官方例程的两处差异"）。

## 三、首次上电顺序（重要）

`Main/main.h` 里的 `DEBUG_MODE` 是分步自检开关，**第一次上电别直接跑正式模式**。

> **仓库默认 `DEBUG_MODE = 1`（自检模式），上电不会驱动未标定的舵机；完成舵机标定、确认无堵转后，再手动改成 0 进入正式模式。**

| 值 | 含义 | 什么时候用 |
|---|---|---|
| `1` | 不初始化舵机：跑一遍跑马灯 → OLED 显示自检图案 → 串口回显 | 第一次上电，验证板子/屏幕/串口 |
| `2` | 单舵机测试：四腿轮流慢扫 0→90→180→0 | 装舵机时确认方向和行程（先只接一个） |
| `0` | 正式模式：语音 + 动作 + 表情 + 灯 | 机械装好、各模块验证通过后 |

改完记得重新编译下载：`F7` → `F8`。

## 四、引脚分配

| 功能 | 引脚 | 说明 |
|---|---|---|
| LED0 / LED1 / LED2 | PE3 / PE4 / PG9 | 板载，低电平点亮 |
| 左后 LB | PD12 | TIM4_CH1 |
| 右后 RB | PD13 | TIM4_CH2 |
| 左前 LF | PD14 | TIM4_CH3 |
| 右前 RF | PD15 | TIM4_CH4 |
| OLED SDA / SCL | PG3 / PG4 | 软件 I2C（与老师代码一致，接反不亮） |
| SU03T TX → 单片机 RX | PC7 | USART6_RX |
| SU03T RX ← 单片机 TX | PC6 | USART6_TX |
| SU03T 电源 | 5V | 实物标称 3.6~5.5V，用 5V；不要加 6V 以上 |
| 舵机电源 | 外部 5V，共地 | 不要四路都吃板载 5V（板载 1A 保险） |

## 五、参数速查

| 项目 | 参数 |
|---|---|
| 系统时钟 | HSE 8MHz → PLL → 168MHz |
| TIM4 | PSC=840-1 → 100kHz；ARR=2000-1 → 20ms；写入前限幅 CCR 60~240（0.6~2.4ms） |
| 角度公式 | 左腿 `CCR = angle*50/45 + 50`；右腿 `CCR = 250 - angle*50/45`（先乘后除） |
| 舵机速度 | 全局 `speed`：0=一步到位，数值越大越慢（每步延时 ms） |
| 语音串口 | USART6，9600-8-1-无校验，帧格式 `AA 55 + 数据 + 55 AA` |
| 表情尺寸 | 静态 5 张 128x64；吼叫动图 6 帧 107x64（起点 x=10） |
| 动图帧率 | 每帧 65ms ≈ 15 帧/秒 |

## 七、换成自己的表情

`USER/OLED/oled_picture.c` 现在是程序生成的占位表情。换成自己的图：

1. 用 **Image2Lcd 2.9** 取模：图形模式 / C51 格式 / 行后缀空 / 单色 1bit。
   静态表情 128x64，动图帧 107x64。
2. 把生成的数组内容覆盖 `oled_picture.c` 里对应的数组（函数不用改）。
3. 显示不对时改 `USER/OLED/oled.h` 里的开关：
   - 颜色黑白颠倒 → `OLED_PIC_INVERT` 改成 1
   - 图案上下颠倒 → `OLED_PIC_BIT_REVERSE` 改成 1
   - 屏幕花屏/点不亮 → `OLED_I2C_SPEED` 改成 2（给软件 I2C 加更多延时）

> 注：原表情 / 工程生成脚本（`gen_face.py`、`gen_project.py`）含本机绝对路径，不随仓库发布；修改表情请按上面的取模流程手动替换数组。

## 八、与官方例程的两处差异（答辩可讲）

启明欣欣的例程是 2015 年用 Arm Compiler 5 写的，本工程改用 Arm Compiler 6 编译，
为此做了两处等价修改：

1. `Common/common.c`：原来用 `__asm` 关键字写内联汇编（`WFI_SET` 等 4 个函数），
   AC6 不支持这种写法，改用 CMSIS 标准内建函数 `__WFI()/__disable_irq()/__enable_irq()/__set_MSP()`。
2. `STM32F4_FWLIB/src/misc.c`：标准库用 `NVIC->IP[]` 写中断优先级，
   CMSIS 6 把该成员改名为 `NVIC->IPR[]`，改用标准接口 `NVIC_SetPriority()`。

另外 `CMSIS_Core/` 目录里放的是现代 CMSIS 内核头文件，替换了例程里 2014 年的旧版
（旧版在 AC6 下会报 `unknown register name 'vfpcc'`）。

### 与老师后课截图代码的差异（这几处是刻意改对的，答辩可讲）

3. 老师截图的 `Set_RF_Angle` / `Set_RB_Angle` 里，`Speed == 0` 分支调用的是
   `PWM_LB(j)`（复制粘贴遗留），我们按通道分别调用 `PWM_RF` / `PWM_RB`。
4. 老师截图里读"当前位置"用了 `TIM_GetCapture4()`（左右腿都一样），
   我们给每条腿单独保存当前 CCR，避免读到别的通道。
5. 前进方向：老师实测"90° → 45° 是向前摆"，所以前进摆到 45°、后退摆到 135°
   （最初的版本把这两个方向写反了，已修正）。
6. OLED 引脚按老师代码接：**SDA → PG3，SCL → PG4**；软件 I2C 每个边沿延时 1us
   （`OLED_I2C_SPEED = 1`）。接反了屏幕完全不亮。

## 九、还没在硬件上验证的部分（务必按 Docs 里的清单逐项确认）

代码已编译通过，但**舵机方向与行程、OLED 位序、SU03T 实际通信**都必须上电实测，
这几项取决于你的舵盘安装角度和接线，代码里留了对应的调整开关与宏：

- 舵机方向反 → 断电拆舵盘旋转 180° 重装（老师视频做法），或调整 `servo.h` 的公式
- 步态幅度不合适 → 改 `servo.h` 里的 `GAIT_SWING`（默认 45°）
- 摆动速度不合适 → 改 `servo.h` 里的 `SPEED_GAIT`（默认 3ms/步，数值越大越慢）
