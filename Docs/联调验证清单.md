# 联调验证清单（做一步勾一步）

按顺序做，每步通过再进入下一步。前 3 步不需要舵机。

| # | 内容 | 通过标准 | 怎么做 |
|---|---|---|---|
| 1 | 工具链闭环 | Keil 编译 0 错误 0 警告，下载后 LED 轮流亮 | `DEBUG_MODE = 1` 编译下载，看板上三盏灯跑一遍 |
| 2 | OLED 自检 | 屏幕出现外框 + 对角线 + 0~9 数字，左上角有实心方块 | 同上（模式 1 会自动显示）。花屏 → `OLED_I2C_SLOW` 改 1；上下颠倒 → `OLED_PIC_BIT_REVERSE` 改 1 |
| 3 | 串口收发 | 串口助手发 `01`，屏幕右上角显示 `1` | 模式 1 + 串口助手（9600 8 1 无校验）；若要看回显把 `usart6.h` 的 `USART6_ECHO_DEBUG` 改成 1 |
| 4 | 单舵机方向（**先收窄脉宽再试**） | 一条腿缓慢摆动，方向与预期一致，全程没有"嗡嗡"堵转声 | `DEBUG_MODE = 2`，**先只接一个舵机**（接 PD12）。SG90 是塑料齿，进这一步前先把 `servo.h` 里 `SERVO_CCR_MIN/MAX` 改成 **60/240** |
| 5 | 四腿归位 | 上电四腿自动摆到"趴下、腿尖朝前"的对称姿态 | `DEBUG_MODE = 0`，四个舵机都接好，上电观察 |
| 6 | 起立 / 趴下 / 坐下 | 喊「起立」四腿立起；「趴下」四腿收回；「坐下」前腿抬、后腿趴 | 正式模式，语音逐条喊 |
| 7 | 前进 / 后退 | 前进时对角腿交替摆动并能实际向前位移；后退反向 | 若只原地踏步：`servo.h` 里把 `SPEED_GAIT` 调大（如 5）或减小 `GAIT_SWING` |
| 8 | 语音→指令 | 喊「起立」，右上角出现 `1`；喊「开灯」出现 `6` | 正式模式；若不出现，先看第 3 步串口是否通，再查 SU03T 固件波特率/引脚 |
| 9 | 静态表情 | 1/3 显示快乐、2/4/5 显示平静，无花屏 | 正式模式逐条喊 |
| 10 | 动态表情 | 喊「开灯」三灯点亮并循环播放 6 帧吼叫动图；喊「关灯」停止并恢复平静 | 正式模式 |
| 11 | 开灯 / 关灯 | 三盏灯全亮 / 全灭，同时开始 / 停止动态表情 | 正式模式 |
| 12 | 供电稳定 | 四腿同时动作时板子不复位、屏幕不闪、舵机不抖 | 若复位：检查舵机是否独立供电、是否共地 |
| 13 | 代码体积 | Keil 输出 `RO-data + Code` ≤ 28KB | 看 Build Output 的 `Program Size` 一行 |

## 调试小技巧

- **保护舵机**：SG90 塑料齿堵转容易扫齿。四条腿装好后先用手轻推感受行程，
  确认机械上没有干涉；再把脉宽范围从 60~240 逐步放开到 50~250，
  只要听到持续"嗡嗡"声或发烫，立刻断电并收窄范围。

- **先看数字再动作**：主程序会把收到的指令号显示在 OLED 右上角，
  所以喊完指令先看屏幕数字对不对，能快速区分"语音没识别"和"动作有问题"。
- **不接语音也能测**：用串口助手直接发 `01`~`09` 的十六进制，
  等价于语音模块发指令，可以脱离语音模块调试动作和表情。
- **改完模式记得重新编译下载**（F7 → F8）。
