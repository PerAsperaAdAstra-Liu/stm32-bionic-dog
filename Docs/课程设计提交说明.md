## 提交内容

## 系统概述

系统以 STM32F407ZGT6 为主控，SU-03T 完成离线语音识别，USART6 接收命令字节。TIM4 输出四路 20 ms PWM 驱动四个 SG90 舵机，OLED 通过软件 I2C 显示表情，三盏板载 LED 提供灯光反馈。

## 编译与下载

- 开发环境：Keil MDK 5.43a，Arm Compiler 6.24
- 下载器：ST-Link
- 目标器件：STM32F407ZGT6
- 编译结果：0 Error，0 Warning
- 只读占用：约 15.6 KB

打开 `04_软件与固件/Dog_V1/Project/Dog.uvprojx`，确认 Debug 页选择 `ST-Link Debugger`，Port 为 SWD，然后执行编译和下载。

## 操作说明

1. 唤醒词：旺财一号、你好旺财。
2. 基础指令：起立、趴下、坐下、前进、后退、开灯、关灯。
3. 动态表情快捷演示：说“开灯”启动吼叫动图，说“关灯”停止并恢复平静。
4. 8、9 号表情分支可用串口助手发送 `08`、`09` 测试。
