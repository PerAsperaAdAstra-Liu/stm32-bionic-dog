### ⚠ 需要你决定的一件事：8 号和 9 号指令现在喊不出来

平台配置里，只有 7 条命令词配了"串口发送"：

| 动作 | 命令词 | 串口发送 | 说明 |
|---|---|---|---|
| A1~A7 | 起立 / 趴下 / 坐下 / 前进 / 后退 / 开灯 / 关灯 | ✅ 发 `1`~`7` | 程序已对应 |
| A8 / A9 | 最小音量 / 最大音量 | ❌ 只调音量 | 与单片机无关 |
| A10 | 打劫 | ❌ 只播"害怕"音频 | **没有字节发给单片机** |
| A11 | 滚 | ❌ 只播"腆着脸"音频 | **没有字节发给单片机** |
| A12 | 串口输入触发 | 收到 `AA 55 0C 55 AA` 回播 | 用来测通信 |

程序已经把 `开灯(6)` 复用为动态表情快捷入口：喊「开灯」启动吼叫动图，
喊「关灯」停止并恢复平静。因此当前固件无需重新生成，也能完整展示动态表情。

直接发送 `8` / `9` 的独立入口仍然可用；只是喊"打劫/滚"时模块只会播放音效，
不会向单片机发送对应字节。

想启用这两个表情，在平台上做两步（很快，主要是重新生成固件要排队）：

1. 命令词 `打劫` 的响应里**再加一个控制项**：串口发送 `8`；
2. 命令词 `滚` 的响应里**再加一个控制项**：串口发送 `9`。
3. 重新点"保存并生成固件"，下载新的 `.bin` 重新烧录。

> 另外把两条命令词补进最终报告与答辩 PPT 时，用实际口令"打劫/滚"，
> 不要写开题报告里的"叫/吼叫"。

## 一、创建产品

1. 打开浏览器搜索「智能公园」进入平台，注册/登录。
2. 产品管理 → 所有产品 → 创建产品。
3. 选型路径：**RGB 灯 → 离线方案 → 模块型号 SU03T**。
4. 产品名称：`旺财一号`；语言：中文。

## 二、引脚与串口（红色引脚不可改）

| 项目 | 设置 |
|---|---|
| 前端信号处理 | 默认；麦克风距离选「近」 |
| 串口接收 RX | **7 号引脚（B7）** |
| 串口发送 TX | **8 号引脚（B6）** |
| 串口参数 | 9600、8 数据位、1 停止位、无校验 |
| 通信帧格式 | `AA 55 + 数据 + 55 AA` |

> 21/22 号引脚（B2/B3）也能复用成串口，本项目不用，二选一即可。

## 三、唤醒词

| 唤醒词 | 回复语（示例） | 灵敏度 |
|---|---|---|
| 旺财一号 | 我在 | 中 |
| 你好旺财 | 好的 | 中 |

## 四、命令词（核心）

每条都是「触发方式 = 命令词」，控制方式选「串口发送」，发送对应数字字节。

| 编号 | 命令词 | 串口输出 | 回复语 |
|---|---|---|---|
| A1 | 起立 | `1`（0x01） | 好的 |
| A2 | 趴下 | `2`（0x02） | 好的 |
| A3 | 坐下 | `3`（0x03） | 好的 |
| A4 | 前进 | `4`（0x04） | 好的 |
| A5 | 后退 | `5`（0x05） | 好的 |
| A6 | 开灯 | `6`（0x06） | 好的 |
| A7 | 关灯 | `7`（0x07） | 好的 |
| A8 | 吼叫 | `8`（0x08） | 上传咆哮声 MP3 |
| A9 | 滚 | `9`（0x09） | 上传委屈/哽咽声 MP3 |

## 六、生成固件

1. 全部配置完成后点「保存并生成固件」。
2. 平台高峰期可能排队数十分钟，下载得到 `.bin` 固件文件。
3. 把固件保存到一个**全英文路径**的文件夹里（烧录软件对中文路径不友好）。

## 七、烧录固件（硬件操作，小心）

接线（USB 转 TTL / CH340）：

| USB 转 TTL | SU03T 模块 | 说明 |
|---|---|---|
| 5V | VCC | 5V（标称 3.6~5.5V） |
| GND | GND | 共地 |
| TXD | B7 | 模块的 RX |
| RXD | B6 | 模块的 TX |

> 如果模块装在厂商配的**转接板**上：直接接转接板上的 4 针烧录接口
> （丝印 5V / RXD / TXD / GND），转接板上有复位按键，按提示复位更方便。

步骤：

1. **先拔掉咪头和喇叭**（严禁短路，短路会烧模块）。
2. 保持模块通电，打开烧录软件 → 选择 `.bin` 固件 → 点「烧录」。
3. 软件提示等待时，**断开 VCC 再重新接通**，完成复位。
4. 等待烧录完成，断电后把咪头、喇叭接回去。

## 八、烧录后验证

1. 上电应播报欢迎语（若开机播报配的是"无"，则没有声音，正常）。
2. 唤醒：「旺财一号」→ 模块有回复语。
3. 串口验证：USB 转 TTL 接电脑，打开串口调试助手
   （**9600、8、1、无校验，16 进制显示**）：
   - 说「起立」→ 收到 `01`
   - 说「开灯」→ 收到 `06`
4. 串口输入验证：发送 `AA 55 0C 55 AA` → 模块播报（串口输入触发功能通）。

> 常见问题：① 波特率或引脚两端不一致 → 收不到数据；② 烧录失败 → 检查路径是否含中文、
> 是否按提示重新上电复位、咪头喇叭是否已拔掉。
