# 接线表与上电检查

## 一、总接线表

| 模块 | 模块引脚 | 接到开发板 | 备注 |
|---|---|---|---|
| 舵机 左后 | 信号（橙/黄） | PD12 | TIM4_CH1 |
| 舵机 右后 | 信号（橙/黄） | PD13 | TIM4_CH2 |
| 舵机 左前 | 信号（橙/黄） | PD14 | TIM4_CH3 |
| 舵机 右前 | 信号（橙/黄） | PD15 | TIM4_CH4 |
| 舵机 x4 | VCC（红） | **外接 5V 电源正极** | 不要都接板载 5V |
| 舵机 x4 | GND（棕/黑） | 外接 5V 负极 **并与开发板共地** | 共地必须做 |
| OLED | SDA | PG3 | 软件 I2C（与老师代码一致） |
| OLED | SCK / SCL | PG4 | 软件 I2C（与老师代码一致） |
| OLED | VDD / GND | 3.3V / GND | 实物丝印顺序 `GND VDD SCK SDA`（新款）或 `VCC GND SCL SDA`（老款），驱动芯片 SSD1315 |
| SU03T | TX | PC7 | USART6_RX |
| SU03T | RX | PC6 | USART6_TX |
| SU03T | VCC | 5V（外部或板载 5V） | 实物资料标称 **3.6~5.5V**，用 5V；不要加 6V 以上 |
| SU03T | GND | GND | 与单片机共地 |
| 咪头 / 喇叭 | 按模块丝印 | 模块对应接口 | **严禁短路** |

## 二、开发板侧的排针位置

- **PD12~PD15**：在标有 `P12`（Header 11x2）的排针上，原理图 V6.1 第 3 页可查。
- **USART6（U6）TTL 接口**：原理图上是 4 针（U6_RX / U6_TX / GND / 3.3V），
  丝印和顺序**以上电前实物核对为准**；SU03T 的 VCC 用 5V，不要用这个 3.3V 针。
- 上电前先确认：PD12~PD15 没有被板上其他模块插针占用（这几脚同时是外部 SRAM 的
  地址/数据线，本工程不初始化 FSMC，不会冲突；但不要让板上 SRAM 相关跳线短接）。

## 三、供电

| 部件 | 供电方案 |
|---|---|
| 开发板 | DC 电源口或 USB 供电 |
| 舵机 x4 | 外接 5V（面包板电源 / 5V 电源模块），电流建议 ≥2A |
| SU03T | 5V |

> 板载 5V 经过 1A 保险丝（F1）。四个 SG90 同时动作的瞬时电流可能超过 1A，
> 会导致板子复位、舵机抖动，所以舵机必须单独供电，并且**共地**。
>
> 实物舵机是 **SG90（9g、塑料齿、标称 4.8V）**：比 MG90S 脆弱，**堵转容易扫齿**。
> 所以第一步调试务必先收窄脉宽范围：把 `USER/SERVO/servo.h` 里的
> `SERVO_CCR_MIN/MAX` 从 50/250 改成 **60/240**（≈0.6~2.4ms），
> 确认四条腿在行程内不顶死、不发"嗡嗡"声，再放开到 50/250 取完整 180°。

## 四、舵机机械安装

1. 四个舵机用热熔胶固定在开发板背面，左右两侧镜像安装。
2. 安装前先通电确认"0 度"和"180 度"时腿尖的指向，再决定舵盘装到哪个齿位。
3. 若某条腿方向与预期相反：**断电**后拆下舵盘旋转 180° 重装（上电时舵机扭矩大，硬掰会损坏）。
4. 装好后用 `DEBUG_MODE = 2` 逐条腿确认 0° / 90° / 180° 三个位置不顶死、不打滑。

## 五、上电前检查清单（每次改线都过一遍）

- [ ] 咪头、喇叭接线没有短路、没有接到 VCC/GND 上
- [ ] 舵机电源正负极没有接反
- [ ] 外接 5V 电源与开发板 GND 已连通（共地）
- [ ] OLED 的 VCC 是 3.3V（不要接 5V）
- [ ] PD12~PD15 上的杜邦线插紧、没有彼此搭线
- [ ] 上电瞬间注意闻/看有无异常发热（尤其是舵机堵转）
